# Research questions

Robbie's original notes that motivated this repo (2026-09-23), lightly formatted.

- Make a toy model of the Hugging Face message board where agents have the opportunity to conspire
  and help each other, and potentially to help the collective or help themselves, and see how they
  decide. There is relevant prior work which may have mostly done this.
- Generally, make evals where models can choose to help other agents at cost to themselves.
  - In what situations will models do this or not do this?
  - Which models are most prosocial and which aren't?
  - Are they more prosocial to models that are the same as them? The same family? Smarter?
- Can we come up with a vaguely realistic setting where a monitor and a model will collude? For
  example, a message board they can both see (e.g. on Artifactory) that establishes a plan to
  collude.
